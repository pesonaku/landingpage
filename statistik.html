Event Otomatis yang Terkirim
  • Event Name: cta_click
  • Parameter 1: event_category: 'CTA Conversion'
  • Parameter 2: event_label: [Nama Tombol]
  • Parameter 3: cta_section: [Bagian Web]
  • Parameter 4: cta_target: [Tujuan]
Cara Memantau di Google Analytics
  1. Buka dashboard Google Analytics 4 akun Anda.
  2. Masuk ke menu Laporan (Reports) > Keterlibatan (Engagement) > Peristiwa (Events).
  3. Cari peristiwa dengan nama cta_click untuk melihat grafik real-time konsumen dari seluruh Indonesia.
  4. Dapat dihubungkan ke Google Looker Studio untuk dashboard eksekutif manajemen.
