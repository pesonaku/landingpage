Event Otomatis yang Terkirim
  • Event Name: cta_click
  • Parameter 1: event_category: 'CTA Conversion'
  • Parameter 2: event_label: [Nama Tombol]
  • Parameter 3: cta_section: [Bagian Web]
  • Parameter 4: cta_target: [Tujuan]
Cara Memantau di Google Analytics
  1. Buka dashboard Google Analytics 4 akun Anda.
  2. Masuk ke menu Laporan (Reports) > Keterlibatan (Engagement) > Peristiwa (Events).
  3. Cari peristiwa dengan nama cta_click untuk melihat grafik real-time konsumen dari seluruh Indonesia.
  4. Dapat dihubungkan ke Google Looker Studio untuk dashboard eksekutif manajemen.

Sinkronisasi Multi-Device Google Sheets

Mencatat seluruh klik CTA dan formulir leads calon pembeli dari semua perangkat (HP, tablet, desktop) ke Google Sheets secara real-time.

Mode Browser Lokal (Belum Terhubung Cloud)
URL Web App Google Apps Script
Masukkan URL Web App Google Apps Script berakhiran /exec untuk menghubungkan dashboard ke Google Sheets.
Langkah Wajib untuk Mencatat dari Browser & HP Lain

Agar seluruh pengunjung website di HP atau browser berbeda otomatis tercatat, tempelkan kode di bawah ke Template Blogger (Theme > Edit HTML / example.xml) sebelum baris main_script.js:

<script> window.PESONA_CLOUD_ENDPOINT = 'MASUKKAN_URL_WEB_APP_ANDA_DISINI'; </script>
Panduan Pasang Google Sheets Backend (Hanya 2 Menit)
  1. Buka https://sheets.new di browser Anda (login dengan Google). Beri nama spreadsheet, contoh: Database Leads Pesona Kahuripan.
  2. Di menu atas Google Sheets, klik menu Ekstensi (Extensions) > Apps Script.
  3. Hapus semua baris kode di Apps Script, lalu tempel (paste) kode backend dari berkas google-apps-script.js di repositori ini.
  4. Klik tombol biru Terapkan (Deploy) > Penerapan Baru (New deployment).
  5. Pilih jenis Aplikasi Web (Web App). Atur:
    • Jalankan sebagai: Saya (akun Google Anda)
    • Akses: Siapa saja (Anyone) (Wajib agar pengunjung web bisa mengirim data lead)
  6. Klik Terapkan (Deploy) > berikan izin akses > salin URL Aplikasi Web yang berakhiran /exec.
  7. Tempel URL tersebut pada kolom input di atas lalu klik Simpan & Hubungkan.
Berkas backend siap pakai: google-apps-script.js
